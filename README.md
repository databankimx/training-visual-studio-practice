# Visual Studio practice repository

This repository is used with the Using the Visual Studio IDE tutorial. You create it from the template, open the solution in Visual Studio 2026, and work through the lessons there.

## What is here

- `PracticeSolution.sln`: the solution, with three projects.
- `Pricing`: a class library with four functions for a list of prices: `Total`, `Average`, `MaxPrice`, and `MinPrice`.
- `Pricing.Tests`: NUnit tests for `Pricing`. One test fails on purpose, and the lessons on debugging and the capstone fix it.
- `PriceReport`: a console app that prints a total for a list of prices.

## Requirements

- Visual Studio 2026, with the .NET desktop development workload.
- The .NET 10 SDK, which the workload installs.
- A GitHub account of your own, if you publish this repository.

## Getting started

1. Clone the repository from your GitHub account, or create one from the template.
2. Open `PracticeSolution.sln` in Visual Studio.
3. Build the solution with Ctrl+Shift+B. It should build with no errors.

## Notes

- This repository is for learning. Do not put company code, company accounts, or company data in it.
- Copilot is used only with this sample code, and only with a personal account on the free tier.
